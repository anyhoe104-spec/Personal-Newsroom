プライバシー・利用規約・出典

制定日：2026年10月27日（草案）

このアプリについて

Personal Newsroom は、公開されているニュースの RSS から毎日記事を選び、見出し・短い要約・原文へのリンクを表示する読み物アプリです。記事の評価や保存は、あなたの端末の中だけで学習に使われます。

プライバシーポリシー

  • 端末内だけに保存します。評価・あとで読む・既読・関心タグ・設定は、お使いのブラウザの保存領域（localStorage）にだけ保存します。運営者のサーバーへ送信することはありません。
  • アカウント・広告・アクセス解析はありません。Cookie による追跡や、第三者の解析ツール・広告は使っていません。
  • 配信には GitHub Pages を使っています。ページを開くと、配信元の GitHub, Inc. がアクセスログ（IPアドレスなど）を記録する場合があります。取り扱いは GitHub のプライバシーステートメントに従います。
  • 要約・翻訳は配信前に作成しています。英語記事の日本語訳と要約は、毎日の配信前に運営者側で Anthropic 社の API を使って作成します。あなたの評価や端末の情報が API に送られることはありません。
  • 原文のサイトを開いたときは、そのサイトのプライバシーポリシーが適用されます。
  • バックアップで書き出したファイルは、あなた自身が管理してください。設定の「データを初期化」で、端末内のデータをすべて削除できます。

利用規約

  • このアプリは無料で、現状のまま提供します。記事の内容・要約・翻訳の正確性や完全性は保証しません。重要な判断の前には、必ず原文を確認してください。
  • このアプリの利用によって生じた損害について、運営者は責任を負いません。
  • 機能・掲載内容・提供は、予告なく変更・停止することがあります。
  • アプリのソースコードは MIT ライセンスで公開しています。記事の内容とテーマ設定は、このライセンスの対象外です。

出典と著作権

  • 記事の著作権は、それぞれの配信元に帰属します。各記事には配信元の名前と原文へのリンクを表示します。
  • 表示するのは、見出し・短い要約・原文へのリンクです。本文の全文は掲載しません。
  • 要約・翻訳・「影響」の解説には、AI が生成した文章が含まれ、誤りを含むことがあります。
  • 掲載の停止や訂正のご依頼は、下記の連絡先までお知らせください。確認のうえ対応します。
